# Этап 3 — Персонализация: план

Noctis — платформа; Nils (Нильс) — слово пробуждения и имя ассистента (не меняется).

## Цели
1. **Слово пробуждения**: выбор из готового списка (Нильс — по умолчанию, «Привет ESP», Hi/Hallo/Hola/Bonjour ESP,
   Alexa, Computer, Jarvis) или своя фраза (`custom:<фраза>`); модель «Нильс» и обучение своей фразы — этап 4.
2. **Голос**: мужской (`aidar`, по умолчанию) / женский (`xenia`) для русского; голоса для en/es/de/fr.
   Влияет только на TTS.
3. **Характер**: 10 пресетов (по умолчанию «дружелюбный»), меняют системный промпт LLM (стиль, лексика, тон).
4. **Язык** (ru/en/es/de/fr): язык распознавания (Whisper), ответа LLM, синтеза и служебных фраз сервера.
5. **Синхронизация**: настройки пользователя → устройства (новые наследуют; «применить ко всем»),
   изменение на устройстве доходит до колонки сразу (этап 2).
6. **Предпрослушивание** для будущих экранов приложения/сайта: справочник (названия и описания на 5 языках),
   пример фразы характера, аудио-образец голоса.

## Архитектура
`catalog.py` (справочники, 5 языков) → `personalization.py` (чистая логика без GPU: промпт = база языка +
режим длины + характер; голос по языку и полу; фразы сервера) → `voice/assistant.py` (применяет настройки
устройства на трёх шагах: STT-язык, промпт LLM, голос TTS) → `voice/gateway.py` (настройки берутся из
подключения устройства) → `routers/personalization.py` (справочник, образцы, «применить ко всем»).
Тяжёлые зависимости в `voice/pipeline.py` подключаются лениво — логика тестируется без torch/GPU.

## Файлы
Новые: `server/noctis_server/personalization.py`, `routers/personalization.py`,
`tests/test_personalization.py`, `docs/stage3-personalization-report.md`.
Изменяются: `catalog.py`, `schemas.py` (проверка слова пробуждения), `voice/pipeline.py`,
`voice/assistant.py`, `voice/gateway.py`, `main.py`, прошивка `noctis_core` (проверка слова — те же правила).

## Тесты
Все 10 характеров × 5 языков дают промпт; характер и язык попадают в запрос к LLM; голос выбирается
по языку и полу (с запасным вариантом); служебные фразы на 5 языках; проверка слова пробуждения
(пресет / своя фраза / мусор) совпадает на сервере и в прошивке (общая Си-логика через виртуальную колонку);
справочник, образцы, WAV-предпрослушивание, «применить ко всем»; регресс этапов 1–2.

## Критерии приёмки
1. Смена голоса/характера/языка через API меняет поведение следующего же ответа без перезапуска.
2. Умолчания: Нильс / мужской голос / дружелюбный / русский.
3. Некорректные значения отклоняются (сервер) и исправляются (прошивка).
4. Все тесты проходят, прошивка собирается.
5. Ограничения (голоса es/de/fr требуют проверки на слух; модель «Нильс» — этап 4) задокументированы.
