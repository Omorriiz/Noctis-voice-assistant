# Этап 4 — Слово пробуждения «Нильс» (microWakeWord): отчёт

Noctis — платформа; Nils (Нильс) — слово пробуждения и имя ассистента (не менялись). План: [stage4-wakeword-plan.md](stage4-wakeword-plan.md).
Версия прошивки: **0.3.0**. Работает нативно на Windows, без WSL.

## Что сделано

**Модель «Нильс» обучена** (на вашем ноутбуке, CPU, ≈ 30 мин): `wakeword/models/nils.nwwm` (62 КБ), метрики — в `wakeword/models/README.md`.
Положительные примеры синтезированы голосами Silero (5 русских голосов × скорость × высота × интонация), добавлены 1 600 слов-«обманок»,
аугментация шумом/реверберацией, негативы — готовые наборы microWakeWord (≈ 6 ГБ признаков).

**Независимая проверка** другим движком (Windows SAPI «Irina»): при пороге 0,95 и окне 8 — **полнота 81,8 %** (54 из 66 произнесений),
**0 срабатываний на 66 словах-обманках**, **0 ложных срабатываний за 47 минут** обычной русской речи (1,3/час при пороге ≤ 0,90 и полноте 90,9 %).
Порог подбирался по этому же набору — оценка оптимистична; набор небольшой и из одного голоса.

**Прошивка** (`components/noctis_wakeword`, `main/wakeword_sync.c`):
- детектор microWakeWord: микро-фронтенд TFLM → потоковая int8-модель (TFLite Micro) → скользящее окно вероятностей;
- движок выбирается при загрузке по слову: `nils` / `custom:<фраза>` → microWakeWord, пресеты (Привет ESP, Hi/Hallo/Hola/Bonjour ESP, Alexa,
  Computer, Jarvis) → esp-sr WakeNet; **смена слова — без перепрошивки приложения** (сохранение + перезапуск);
- модель читается прямо из раздела `wakeword` (контейнер NWWM, SHA-256); нет модели → временно «Привет ESP» и сообщение на экране;
- доставка модели: `config` содержит `wake_model {sha256,size}`; при отличии от установленной прошивка скачивает контейнер (аутентификация
  устройства), проверяет SHA-256 и структуру **до** записи, пишет в раздел, проверяет чтением, перезагружается; неудачная загрузка не повторяется в цикле;
- в раздел `model` добавлены 7 готовых слов esp-sr (3,35 МБ из 8).

**Сервер**: таблица `wake_models` (миграция 0002), `PUT/GET/DELETE /api/v1/wakewords` (админ), `GET /api/v1/device/wakeword/{sha256}` (устройство),
`wake_model` в `config`, `model_ready` в каталоге слов, автоимпорт готовых моделей из `wakeword/models` при старте.

**Инструменты** (`wakeword/`): `setup_windows.ps1`, `prepare_data.py`, `make_samples.py`, `record_samples.py`, `build_features.py`, `train.py`,
`check_model.py`, `pack_model.py` (контейнер + загрузка на сервер), `make_sapi_eval.ps1` + `evaluate.py`, `README.md` (пошаговая инструкция для своей фразы).

## Не проверено на плате (нужна плата) и ограничения

1. **Инференс TFLite Micro и микро-фронтенд на ESP32-S3 не запускались**: проверены компиляция, побитовый паритет фронтенда на ПК, совместимость набора
   операций модели и логика окна/контейнера. Реальная задержка, загрузка CPU и стек (задача `afe_feed` увеличена до 12 КБ) — на плате.
2. **Качество на живом голосе неизвестно**: обучение и проверка — на синтетике (Silero) и голосе SAPI «Irina». Односложное слово заметно сложнее фраз
   из 3–4 слогов; для реального использования рекомендуется добавить **свои записи** (`record_samples.py`, 30–100 примеров) и переобучить (≈ 40 мин).
3. Модель зависит от лицензий наборов (смешанные) → только личное/некоммерческое использование; для публикации приложения потребуются данные с открытой лицензией.
4. Смена слова приводит к перезапуску устройства (≈ 5 с); переключение «на лету» без перезапуска не реализовано (esp-sr не позволяет сменить WakeNet-модель в работающем AFE).
5. BLE-сопряжение/экран/OTA (этап 2) по-прежнему не проверены на плате; чек-лист — в отчёте этапа 2.
6. Данные для обучения (≈ 25 ГБ) лежат в `C:\Users\yumit\Desktop\Noctis\wake_train` и в архив не входят; окружение воспроизводится `setup_windows.ps1`.

## Чек-лист проверки на плате

1. `pio run -t erase`, `pio run -t upload` (раздел `model` с 8 словами esp-sr). Запустить сервер: он импортирует `nils.nwwm`.
2. Сопрячь колонку; в логе `config` с `wake_model`; затем «Нужна модель слова… → Модель «Нильс» записана → перезагрузка».
3. После перезагрузки: «Слово пробуждения: «Нильс» (движок: microWakeWord)», модель: «вход int8 [1,3,40]…, арена … использовано …» (при нехватке арены прошивка увеличивает её сама).
4. Сказать «Нильс» с 0,5–2 м: «Нильс! Говорите команду…»; посчитать пропуски и ложные срабатывания за 10–15 мин ТВ/разговора.
5. `PATCH /devices/{id}/settings {"wake_word":"computer"}` → перезапуск на esp-sr «Computer»; обратно на `nils` — без повторного скачивания модели.
6. Порог/окно: `pack_model.py --cutoff … --window …` → загрузка на сервер (`--upload`) → колонка скачает новую версию сама.
