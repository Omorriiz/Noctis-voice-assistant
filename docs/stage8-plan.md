## 1. Что уже есть (не переделывать, а проверить тестами)
- Пароли: scrypt (`security.py`), соль на каждый пароль, сравнение через `hmac.compare_digest`.
- Токены: JWT HS256 (access 15 мин), refresh хранится как хэш, ротация, отзыв сессий.
- Ограничение частоты запросов по IP (`ratelimit.py`: 120 в минуту, 10 на вход/регистрацию) — в памяти процесса.
- В режиме `production` сервер не стартует с секретом по умолчанию.
- Роли `user` / `admin`, зависимость `require_admin` (OTA, модели слов).
- Не храним записи голоса (`store_audio=False`), согласие на обработку данных (`consent_at`), удаление учётной записи.
- CORS ограничен списком источников.
