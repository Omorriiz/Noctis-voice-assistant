# Этап 6 — мобильное приложение: план

Задание: мобильное приложение Noctis с тем же стилем, что и сайт (общая палитра, светлая и тёмная тема), иконка — присланное вами изображение.
Ограничения прежние: 5 языков (ru — первым), без push-уведомлений и Firebase Cloud Messaging, без WSL2, без GitHub, один коммит на этап.
Этапы 8 и 9 не затрагиваются.

## Решения
- **Flutter** (проект уже лежит в `app/`). На компьютере Flutter не было: по вашему согласию установлен официальный Flutter SDK 3.47.7 (Dart 3.13.5) в `Noctis\flutter`
  (сам SDK в репозиторий/ZIP не входит). Android SDK не ставился — сборка APK возможна только после отдельного согласия; проверка приложения — анализатором,
  автотестами и запуском в веб-версии (Flutter web) в браузере.
- **Из `app/` убирается всё лишнее от прежнего прототипа**: Firebase (`firebase_core`, `firebase_auth`, `cloud_firestore`, `firebase.json`, `google-services.json`,
  `firebase_options.dart`), MQTT. Прежние экраны переписываются под API сервера Noctis. Сохраняются идеи: BLE-сопряжение ESP-IDF (`flutter_blue_plus`, `esp_provisioning_ble`).
- **Стиль идентичен сайту**: цвета, скругления и шрифты берутся из `site/assets/tokens.json` скриптом `app/tools/gen_tokens.py` (один источник на сайт и приложение);
  космический фон со звёздами и свечением, стеклянные карточки, неоновый градиент в заголовках, кнопки-градиенты, переключатель светлой/тёмной темы, тёмная по умолчанию.
- **Тексты**: строки кабинета сайта (`site/i18n.py`) переиспользуются в приложении, чтобы формулировки совпадали; строки, нужные только приложению
  (сопряжение, меню, настройки), добавляются на 5 языков. Скрипт `app/tools/gen_l10n.py` создаёт Dart-файл. Язык — как в системе, можно выбрать в настройках.
- **Сервер**: конечный пользователь адрес не вводит. Адрес задаёт владелец при сборке (`--dart-define=NOCTIS_SERVER=...`); скрытое меню разработчика (семь касаний по логотипу в «О приложении») позволяет его сменить.

## Экраны
1. Вход и регистрация (согласие на обработку данных). Токены — в защищённом хранилище.
2. Главная с нижней панелью: **Колонка** (состояние, настройки: название, громкость, язык, голос, характер, слово пробуждения, часовой пояс), **Таймеры и будильники**,
   **Музыка** (библиотека, радио, Jamendo, плеер), **История**, **Профиль** (язык, тема, выход, удаление учётной записи, о приложении).
3. **Добавление колонки (сопряжение по Bluetooth)**: разрешения → поиск `NOCTIS_*` → код сопряжения с экрана колонки → Wi-Fi сети и пароль → привязка к серверу
   (endpoint `noctis-config`, как в `server/tools/pair_device.py`) → ожидание статуса «онлайн».

## Что подменяется заглушкой
Bluetooth недоступен в вебе и на этом компьютере без телефона, поэтому сопряжение работает через интерфейс `PairingTransport`: настоящая реализация
(`flutter_blue_plus` + `esp_provisioning_ble`) и заглушка `MockPairing` (для тестов и запуска в браузере: `--dart-define=NOCTIS_MOCK_BLE=true`). Это документируется в отчёте;
проверка настоящего Bluetooth — только на телефоне с платой.

## Проверка
`flutter analyze`, `flutter test` (клиент API, строки на 5 языках, совпадение токенов приложения и сайта, экраны входа и главной, мастер сопряжения на заглушке),
запуск веб-версии против работающего сервера. Не проверяется здесь: сборка APK/IPA, настоящий BLE, поведение на телефоне.
