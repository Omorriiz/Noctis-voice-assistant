# Этап 4 — Слово пробуждения «Нильс» (microWakeWord): план

Noctis — платформа; Nils (Нильс) — слово пробуждения и имя ассистента (не менялись). Всё работает нативно на Windows, без WSL.

## Цели
1. «Нильс» — слово по умолчанию: своя модель **microWakeWord** (TFLite Micro) на ESP32-S3, работает локально.
2. Готовые слова Espressif (Привет ESP, Hi/Hallo/Hola/Bonjour ESP, Alexa, Computer, Jarvis) выбираются без перепрошивки
   приложения; слово «Нильс» и своя фраза — моделью из раздела `wakeword`.
3. Своя фраза пользователя: набор инструментов обучения на ПК (Windows, CPU), загрузка модели на сервер, устройство само её скачивает.
4. Честная оценка качества: ложные срабатывания в час на шумовых наборах, полнота; ограничения (мало голосов для русского) задокументированы.

## Архитектура
**Обучение (ПК, `wakeword/`)**: положительные примеры «Нильс» синтезирует Silero (5 русских голосов × скорость/высота/интонация, SSML) → аугментация
(шум AudioSet/FMA, реверберация MIT RIR, jitter) → признаки (тот же микро-фронтенд, что на плате) → обучение MixedNet (микро-модель) в потоковом
режиме с квантованием int8 → `nils.tflite` + `nils.json` (порог, окно сглаживания, размер арены). Свои записи пользователя можно добавить скриптом `record_samples.py`.

**Плата (`firmware/components/noctis_wakeword`)**: микро-фронтенд TFLM (40 mel-признаков, окно 30 мс, шаг 10 мс, шумоподавление и АРУ) →
потоковая модель в TFLite Micro (esp-tflite-micro) → скользящее среднее вероятностей → срабатывание. Модель читается из раздела
`wakeword` (mmap): контейнер `NWWM` = заголовок + манифест + .tflite + SHA-256. Выбор движка при загрузке по слову пробуждения из NVS:
`nils` / `custom:*` → microWakeWord, пресеты → esp-sr WakeNet (нужная модель в разделе `model`). Смена слова → сохранение в NVS и перезапуск в новый движок.

**Доставка модели**: сервер хранит модели (`wake_models`, миграция 0002; загрузка админом `PUT /api/v1/wakewords/{id}`); `config` содержит
`wake_model {sha256,size}`; если хэш отличается от записанного в разделе — прошивка скачивает модель
(`GET /api/v1/device/wakeword/{id}`, аутентификация устройства), проверяет SHA-256 и **пишет в раздел только после проверки**; затем перезапуск.

**Совместная работа с аудио-конвейером**: микрофон по-прежнему питает AFE (VAD, запись команды); в режиме microWakeWord WakeNet отключён,
а те же отсчёты идут в детектор; после срабатывания логика записи/отправки/воспроизведения прежняя.

## Файлы
Новые: `wakeword/` (скрипты: `setup_windows.ps1`, `make_positives.py`, `train.py`, `export_model.py`, `pack_model.py`, `record_samples.py`, `evaluate.py`,
`README.md`), `firmware/components/noctis_wakeword/*` (фронтенд, модель, контейнер, детектор), `firmware/main/wakeword_sync.c`,
`firmware/wakeword_models/nils/{nils.tflite,nils.json}` (если обучение завершится), `server/noctis_server/routers/wakewords.py`,
миграция `0002`, тесты, `docs/stage4-wakeword-report.md`.
Изменяются: `main.c` (выбор движка), `sdkconfig.defaults` (модели esp-sr, esp-tflite-micro), `idf_component.yml`, `noctis_core` (контейнер/манифест),
сервер: `catalog.py` (доступность моделей), `gateway.py` (`wake_model` в `config`).

## Тесты
Хост-тесты Си: разбор контейнера NWWM (целостность, обрезание, подмена), манифест, скользящее окно, маппинг слова → движок;
паритет микро-фронтенда (Си, собранный на ПК) с обучающим `pymicro-features`; проверка, что операции обученной модели входят в набор,
зарегистрированный в прошивке; сервер: загрузка/выдача моделей, `wake_model` в `config`, права; виртуальная колонка скачивает модель и
отвергает модель с неверным хэшем; сборка прошивки; метрики обученной модели (FA/час, полнота).

## Критерии приёмки
1. Прошивка собирается; хост-тесты и `pytest` проходят.
2. Обучена и упакована модель «Нильс» с отчётом метрик (или причина, почему нет, и готовые команды для запуска на вашем ПК).
3. Смена слова: пресет ↔ «Нильс» ↔ своя фраза не требует перепрошивки приложения; битая/неподписанная по хэшу модель не записывается.
4. Инструкция по обучению своей фразы на Windows работает по шагам.
5. Не проверено на плате — перечислено в чек-листе.
