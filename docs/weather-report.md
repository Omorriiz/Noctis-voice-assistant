# Погода: «какая погода в …?»

Дата: 19.10.2026. Колонка отвечает голосом, какая сегодня погода в любом месте. Источник — **Open-Meteo** (open-meteo.com): бесплатно для
некоммерческого использования, без ключа и регистрации. Данные распространяются по лицензии CC BY 4.0 (указано в подвале сайта).
В запрос уходит только название места; данных о пользователе и устройстве нет.

## Как это работает
1. **Фраза** распознаётся на 5 языках без LLM («какая погода в Казани», «what's the weather in London», «¿qué tiempo hace en Madrid?»,
   «Wie ist das Wetter in Köln?», «quelle est la météo à Paris ?»). Длинные обороты, не похожие на название места, уходят LLM.
2. **Место:** из фразы; если не названо — **домашний город** из настроек колонки; если и его нет — город часового пояса колонки
   («Europe/Moscow» → Москва); если и так не вышло — колонка просит назвать город.
3. **Поиск места** (geocoding-api.open-meteo.com): выбирается самое населённое совпадение (Москва в России, а не в Айдахо).
4. **Прогноз** (api.open-meteo.com): сейчас, максимум и минимум за день, код погоды, вероятность и сумма осадков, ветер.
5. **Фраза словами**, на языке колонки, числа прописью: «Сегодня в Москве пасмурно. Сейчас шесть градусов, днём двенадцать градусов,
   ночью минус два градуса. Осадков не ожидается. Скорость ветра четыре метра в секунду.»

## Что выяснилось на настоящем API (и как решено)
| Проблема | Решение |
|---|---|
| Поиск понимает только начальную форму: «в Москве» → село в Нью-Мексико, «в Париже» → село в Литве, «в Казани» → ничего | Для русского название приводится к именительному падежу библиотекой **pymorphy3** (оффлайн, ≈ 8 МБ словарей; единственная новая зависимость), затем берётся самое населённое место |
| «Нижний Новгород», «Ростов-на-Дону», «Санкт-Петербург», «Лос-Анджелес» — составные названия | Склоняются только прилагательные и главное слово; части после предлога («на Дону») и чужие слова («Лос») не меняются; «Питер», «СПб» — синонимы |
| Озвучивание «в …»: «в Москве», «во Владивостоке», «в Нижнем Новгороде», «в Великих Луках» | Предложный падеж тем же pymorphy3; «во» перед «в/ф + согласная» |
| Запросы к Open-Meteo иногда обрываются (таймаут TLS, как и у Jamendo) | Запросы парой параллельно, до двух раз; поиск места запоминается на сутки, прогноз — на 15 минут |
| «Ветер до четыре метра» — неверная форма после «до» | Фраза перестроена: «Скорость ветра четыре метра в секунду» |

## Домашний город
Новое поле в настройках колонки (приложение 1.3.0 и сайт): «Домашний город». Хранится в БД (`settings.home_city`, миграция `0006`),
не более 80 символов, буквы/пробелы/дефис; пустое значение очищает. На плату оно не нужно — всё решает сервер.

## «Завтра»
По решению заказчика реализована только погода на сегодня. Если спросить «погода завтра…», колонка скажет «Я пока знаю прогноз только на
сегодня» и назовёт сегодняшний.

## Не проверено
Голосовой вопрос на самой колонке (сервер у вас запущен со старым кодом); качество распознавания названий малых городов Whisper'ом.
