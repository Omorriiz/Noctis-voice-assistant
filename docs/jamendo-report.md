# Jamendo: подключение и проверка на настоящем API

Дата: 19.10.2026. Источник музыки Jamendo (Creative Commons) подключён ключом `client_id` (бесплатное приложение на developer.jamendo.com, некоммерческое использование).
Ключ лежит в `server\.env` (`NOCTIS_JAMENDO_CLIENT_ID=…`; файл в git не попадает). Секрет приложения (client secret) проекту не нужен и нигде не хранится.

## Что проверено на живом API
| Проверка | Результат |
|---|---|
| Доступность `api.jamendo.com` и потоков `prod-1.storage.jamendo.com` из сети ноутбука | работает |
| Поля ответа (`id`, `name`, `artist_name`, `album_name`, `duration`, `audio`, `license_ccurl`) | совпали с кодом, менять не пришлось |
| Запросы: пусто (популярное), жанр, исполнитель, русские слова | 10 треков за ≈ 1 с на каждый |
| Декодирование настоящего потока (MP3) | первый звук через ≈ 1 с, скорость ×16 от реального времени |

## Что выяснилось и исправлено
1. **Jamendo в 30–60 % запросов отвечает «success» и пустым списком** (105 байт) — сбой на стороне сервиса, а не «ничего не найдено».
   Раньше ответ «ничего не найдено» звучал бы случайно. Теперь запрос уходит пачкой из 3 параллельных (до 2 пачек), берётся первый непустой ответ.
2. **Теги жанров у Jamendo английские.** Русские слова сопоставляются тегам: «джаз» → jazz, «рок» → rock, «спокойная» → relaxation, «электронная» → electronic,
   «классика» → classical и др. Запрос с названием или исполнителем («Daft Punk», «Кино») ищется по тексту; «punk» в «Daft Punk» жанром не считается.
3. **Кэш на 30 минут:** повторный запрос мгновенный, а при недоступном Jamendo играет прошлый удачный результат.
4. **Лицензия** показывается кратко (`CC BY-NC-ND 3.0`) в приложении и на сайте.
5. **Отказ ключа** (код 5) озвучивается отдельно: «Джамендо не принял ключ доступа» (5 языков), а не «Джамендо недоступен».

## Не проверено
Воспроизведение Jamendo именно на колонке (сервер держит прежний код, пока вы его не перезапустите); качество подбора по настроению («спокойная музыка») — теги Jamendo свободные.
