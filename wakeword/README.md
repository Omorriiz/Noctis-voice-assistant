# Обучение слова пробуждения (microWakeWord) на Windows

Инструменты, которыми обучена модель «Нильс» и которыми пользователь заменяет слово на своё. Всё работает **нативно на
Windows (без WSL)**, на CPU; GPU не нужен (TensorFlow ≥ 2.11 под Windows GPU не поддерживает, а модель крошечная).

Noctis — платформа; Nils (Нильс) — слово пробуждения и имя ассистента по умолчанию. Вторая доступная пользователям фраза, Alexa, встроена в прошивку (esp-sr) и обучения не требует.

## Как это устроено

```
Silero (5 русских голосов × скорость × высота × интонация)  →  примеры слова (16 кГц)      make_samples.py
        + слова-«обманки» (похожие на слово, чтобы не будили)                              make_samples.py --negatives
        + ваши записи с микрофона (по желанию)                                             record_samples.py
  → аугментация (шум AudioSet/FMA, реверберация MIT RIR, усиление) → признаки              build_features.py
  → обучение MixedNet (потоковая int8-модель, ≈60 КБ)  + готовые негативные наборы (речь, шум)   train.py
  → проверка поддержки прошивкой                                                           check_model.py
  → контейнер NWWM (+ загрузка на сервер)                                                  pack_model.py
  → сервер раздаёт модель, колонка скачивает её в раздел wakeword и перезапускается
```

Признаки считает **тот же** микро-фронтенд, что и на плате (побитовое совпадение проверяет `tests/test_frontend_parity.py`).

## Что понадобится

* Windows 10/11, Python 3.12 (в PATH), git, ~**40 ГБ** свободного места (данные ≈ 25 ГБ после распаковки), интернет.
* Время (ноутбук с i5-14450HX, CPU): скачивание данных ≈ 1–1,5 ч (≈ 7 ГБ), примеры 20–30 мин, признаки ≈ 5 мин, обучение 10 000 шагов ≈ 30 мин.
* Лицензии наборов смешанные → **модель только для личного/некоммерческого использования** (достаточно для диплома).

## Шаги

```powershell
cd wakeword
.\setup_windows.ps1 -Work D:\wake                  # 0. окружение (venv, TensorFlow, microWakeWord, PyTorch CPU)
$py = "D:\wake\venv\Scripts\python.exe"

& $py prepare_data.py --workdir D:\wake            # 1. данные: негативные наборы, RIR, шум (докачивается при обрыве)
& $py make_samples.py --workdir D:\wake --phrase "Нильс" --count 2400            # 2. примеры слова
& $py make_samples.py --workdir D:\wake --negatives --count 1600 --seed 7        #    слова-обманки
# (по желанию) & $py record_samples.py --workdir D:\wake --count 30              #    СВОИ записи — улучшают модель на вашем голосе

& $py build_features.py --workdir D:\wake                  # 3. аугментация + признаки (слово)
& $py build_features.py --workdir D:\wake --negatives      #    (обманки)
& $py train.py --workdir D:\wake --steps 10000             # 4. обучение; в конце — метрики на тесте

# (по желанию) независимая оценка голосом Windows SAPI — другой движок, чем обучающий Silero:
#   .\make_sapi_eval.ps1 -Out D:\wake\eval_sapi -TextFile "..\docs\hardware-testing-guide.md"
#   & $py evaluate.py --workdir D:\wake --tflite $m --window 8

# 5. проверка, упаковка, загрузка
$m = "D:\wake\trained_models\wakeword\tflite_stream_state_internal_quant\stream_state_internal_quant.tflite"
& $py check_model.py $m
& $py pack_model.py --tflite $m --wake-word nils --label "Нильс" --cutoff 0.95 --window 8 --out models\nils.nwwm
& $py pack_model.py --tflite $m --wake-word nils --label "Нильс" --upload http://192.168.1.5:8000 --token <access-токен администратора>
```

Своя фраза: `--phrase "Привет Ноктис"` на шаге 2 (пишите так, как слово произносится по-русски) и
`--wake-word "custom:Привет Ноктис"` на шаге 5. Затем в приложении/API выберите слово `custom:Привет Ноктис` — колонка сама
скачает модель. Без сервера: `esptool.py write_flash 0xE20000 models\nils.nwwm` (адрес раздела `wakeword` из `partitions.csv`).

Готовые модели из `wakeword/models/*.nwwm` сервер импортирует при старте сам.

## Выбор порога и окна

Обучение печатает на тестовых наборах таблицу «полнота / ложные срабатывания в час» по порогам. `--cutoff` — порог вероятности,
`--window` — сколько последовательных оценок усредняется (у готовой модели «Нильс» 0,80 и 5; менять их без переобучения можно командой `retune_model.py`; у моделей Home Assistant — 0,97 и 5). Чем **выше порог**,
тем меньше ложных срабатываний и тем чаще колонка «не слышит» слово. Подбирайте по метрикам и по живой проверке на плате.

## Честные ограничения

* **Короткое односложное слово** («Нильс») сложнее для детектора, чем фразы из 3–4 слогов («Окей, Набу»): выше риск ложных
  срабатываний. Если срабатывает слишком часто — обучите фразу подлиннее («Эй, Нильс», `custom:Эй Нильс`) или повысьте порог.
* Положительные примеры синтезированы одним движком (Silero): тест на синтетике **завышает** качество. Для честной оценки и
  лучшей работы на живом голосе добавьте свои записи (`record_samples.py`, 30–100 примеров, разные расстояния и громкость).
* Реальное качество зависит от микрофона, комнаты и голоса: проверяйте модель на плате (руководство — `docs/hardware-testing-guide.md`).
