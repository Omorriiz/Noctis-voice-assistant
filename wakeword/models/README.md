# Готовые модели слов пробуждения

Сервер при старте сам импортирует `*.nwwm` из этой папки (если такой модели ещё нет в БД); устройство получает её через `config`.

## `nils.nwwm` — «Нильс» (Nils), слово по умолчанию

| | |
|---|---|
| Архитектура | microWakeWord MixedNet, потоковая int8, вход `[1,3,40]`, 62 КБ (контейнер NWWM 62 736 байт) |
| Порог / окно | 0,80 / 5 оценок (≈ 150 мс), шаг признаков 10 мс (меняется командой `wakeword/retune_model.py`) |
| Положительные примеры | 2 374 синтеза Silero v5_ru (5 голосов × скорость × высота × интонация × случайная растяжка) |
| Слова-«обманки» | 1 600 синтезов похожих слов (Нил, Нина, Нельсон, Билл, Эльс, Миля, Нить, Привет, Алиса, Окей…) |
| Аугментация | шум AudioSet (500 клипов) и FMA (210), реверберация MIT RIR (270), SNR −5…10 дБ, усиление |
| Негативы | готовые наборы microWakeWord: речь, ужин, тишина/шум (≈ 6 ГБ признаков) |
| Обучение | 10 000 шагов, CPU, ≈ 30 мин; лучшие веса по «average viable recall» |
| Лицензия данных | смешанная → модель для личного/некоммерческого использования |

### Метрики

**Тест обучения** (синтетические положительные Silero + набор `dinner_party_eval`, потоковая квантованная модель):
отказ в слове 39,6 % при 0 ложных/час (порог 0,96); 29,6 % при 0,4/час (0,86); 23 % при 1,5/час (0,74).

**Независимая проверка голосом Windows SAPI «Irina»** (другой движок; 66 произнесений слова с разной скоростью/интонацией, 66 слов-обманок,
47 мин обычной русской речи — чтение документации проекта без слова «Нильс»), окно 8:

| порог | полнота | срабатывания на «обманках» | ложных в час речи |
|---|---|---|---|
| 0,80–0,90 | 90,9 % | 0 % | 1,3 |
| **0,92–0,97** | **81,8 %** | **0 %** | **0,0** |
| 0,98 | 72,7 % | 0 % | 0,0 |
| 0,99 | 54,5 % | 0 % | 0,0 |

(порог выбран по этому же набору, поэтому оценка оптимистична).

### Ограничения

* Односложное слово: качество ниже, чем у моделей Home Assistant на фразах из 3–4 слогов (у них отказ ≈ 3 % при < 1 ложном/час).
  Ориентир по нашим данным — **≈ 80–90 % срабатываний при ≈ 0–1 ложном в час** на чтении речи; на живом голосе и в шумной комнате
  результат может отличаться. Улучшение: свои записи (`record_samples.py`) и/или фраза подлиннее («Эй, Нильс»).
* Качество на плате с микрофоном INMP441 зависит от комнаты и голоса; проверяйте его живыми проверками.
