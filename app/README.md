# Noctis — мобильное приложение

Flutter-приложение для умной колонки Noctis: вход и регистрация, добавление колонки по Bluetooth, настройки голоса и слова пробуждения, таймеры и будильники,
музыка, история диалогов, раздел «Мои данные» (выгрузка, очистка истории, удаление учётной записи).
Пять языков (русский, английский, испанский, немецкий, французский), тёмная и светлая темы. Оформление и палитра те же, что на сайте (`../site/assets/tokens.json`).
Push-уведомлений и Firebase нет.

## Что понадобится

- Flutter 3.47 (Dart 3.13).
- Для Android: Android SDK (платформа 37, build-tools 37, NDK 28.2) и JDK 17 или новее.
- Для iPhone нужен Mac с Xcode — на Windows iOS-версия не собирается.

Сценарии сборки ищут Flutter и Android SDK рядом с проектом: `..\..\flutter` и `..\..\android-sdk`. Если они у вас в другом месте, поправьте пути в `tools\build_android.ps1`
или добавьте Flutter в `PATH`.

## Разработка

```powershell
flutter pub get
flutter analyze
flutter test
```

Запуск на подключённом телефоне или эмуляторе. Адрес сервера задаёт владелец при сборке, пользователь его не вводит:

```powershell
flutter run --dart-define=NOCTIS_SERVER=http://192.168.0.136:8000
```

Показ без колонки и без Bluetooth — веб-версия, где Bluetooth заменён заглушкой:

```powershell
flutter build web --dart-define=NOCTIS_SERVER=http://localhost:8000 --dart-define=NOCTIS_MOCK_BLE=true
cd build\web; python -m http.server 3000      # сервер должен разрешать http://localhost:3000 (CORS)
```

### Проверка соединения

Семь быстрых касаний по логотипу (на экране входа и в «Профиле») открывают скрытое окно: адрес сервера, «Проверить соединение», «Адрес по умолчанию».
Так можно сменить сеть, например перейти на точку доступа телефона, не пересобирая приложение.

## Сборка для Android

```powershell
powershell -ExecutionPolicy Bypass -File tools\build_android.ps1 -Server http://192.168.0.136:8000
```

Скрипт собирает `Noctis-<версия>.apk` (установка на телефон) и `Noctis-<версия>.aab` (Google Play) и кладёт их в папку на два уровня выше проекта. Версия берётся из `pubspec.yaml`.
Адрес сервера вшивается при сборке, поэтому телефон должен до него дотягиваться: либо та же сеть Wi‑Fi, что и у колонки, либо публичный адрес (`-Server https://…`).

Подпись выполняется вашим ключом `android\noctis-release.jks`; пароли лежат в `android\key.properties`. Ни ключ, ни пароли, ни готовые APK и AAB в репозиторий не попадают.
**Сохраните ключ и пароли в надёжном месте: без них нельзя выпускать обновления приложения.** Если `key.properties` нет, сборка подписывается отладочным ключом.

Установка: скопируйте APK на телефон, разрешите установку из этого источника и откройте файл, либо `adb install -r Noctis-<версия>.apk`.
Чтобы пользователи скачивали APK с сайта, положите его в `../site/downloads/`.

## Добавление колонки и смена сети

1. «Добавить колонку» → введите код сопряжения (8 цифр) с экрана колонки. Приложение создаёт колонку на сервере и передаёт ей по Bluetooth адрес сервера, токен и сеть Wi‑Fi.
2. «Колонка» → «Сменить сеть» — когда колонка на связи (при неудаче она возвращается в прежнюю сеть).
3. «Настроить по Bluetooth» — когда колонка не в сети: удержите кнопку на колонке 3 секунды и введите код с экрана. Личность колонки сохраняется.

## Устройство проекта

| Путь | Назначение |
|---|---|
| `lib/theme/tokens.g.dart` | цвета из `site/assets/tokens.json` (создаётся `python tools/gen_tokens.py`) |
| `lib/l10n/strings.g.dart` | строки на пяти языках: кабинет сайта (`site/i18n.py`) и строки приложения (`tools/app_strings.py`); `python tools/gen_l10n.py` |
| `lib/services/api_client.dart` | клиент REST API (обновление токена при 401) |
| `lib/services/pairing.dart`, `ble_pairing.dart` | сопряжение: интерфейс, заглушка `MockPairing` и настоящий Bluetooth |
| `lib/state/app_state.dart` | состояние: вход, колонки, язык, тема |
| `lib/screens/` | вход, главный экран, колонка, таймеры и будильники, музыка, история, профиль, мастер добавления колонки |
| `tools/` | генераторы палитры и строк, сборка Android, подготовка иконки |
| `test/` | клиент API на поддельном сервере, строки и палитра, экраны, мастер сопряжения |

После изменения `site/assets/tokens.json` или `site/i18n.py` выполните `python tools/gen_tokens.py` и `python tools/gen_l10n.py`; тест `consistency_test.dart` проверит, что приложение и сайт совпадают.

Иконка: `dart run tools/make_icon.dart` готовит `assets/icon/*.png` из `tools/icon_source.webp`, затем `dart run flutter_launcher_icons` раскладывает их по платформам.
