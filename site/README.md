# Noctis — сайт и веб-кабинет

Лендинг и кабинет управления колонкой на пяти языках (русский — основной, английский, испанский, немецкий, французский), светлая и тёмная темы.
Своей серверной части у сайта нет: кабинет обращается к API сервера Noctis прямо из браузера.

## Как открыть

**Через сервер Noctis (основной способ).** Сервер сам раздаёт папку `site/`: запустите `python -m noctis_server` и откройте `http://<адрес сервера>:8000/`.
Сайт и API живут на одном адресе, поэтому ни CORS, ни адрес в настройках не нужны, а в брандмауэре достаточно порта 8000.
Страницы: `/` (русский), `/en/`, `/es/`, `/de/`, `/fr/`; кабинет — `dashboard.html` в каждом языке.
Отдаются только страницы, стили, скрипты, картинки и APK; `build.py`, `i18n.py`, `tests/` и README недоступны. Отключить раздачу: `NOCTIS_SERVE_SITE=false`.

**Отдельно, как статический сайт.** Подойдёт любой статический сервер:

```powershell
cd site
python -m http.server 8080
```

или запустите `start-site.bat`. Открывать файлы через `file://` нельзя — браузер запретит запросы к серверу.
Тогда в `assets/config.js` укажите `defaultServer` (адрес вашего сервера, например `https://api.example.com`), а на сервере в `.env` разрешите адрес сайта:
`NOCTIS_CORS_ORIGINS=["https://адрес-вашего-сайта"]` (без пути и без `/` в конце). Для отладки `showServerField: true` добавляет в форму входа поле «Адрес сервера»; для публикации оставьте `false`.

## Кабинет

Вход и регистрация, колонки (настройки голоса и слова пробуждения, домашний город, смена сети Wi‑Fi, удаление), таймеры и будильники, музыка, история диалогов
и вкладка «Мои данные»: выгрузка всех данных в файл, очистка истории и удаление учётной записи.

- **Alt+X** на любой странице открывает `admin.html` (в меню его нет, поисковики его не индексируют): вход почтой и паролем администратора, список пользователей и колонок, действия, журнал.
  Администратора создаёт `server\tools\create_admin.py`. Пароли пользователей не видны никому, есть только «сбросить пароль».
- **Семь быстрых нажатий по логотипу** в кабинете показывают поле «Адрес сервера» с кнопкой «Проверить соединение» — для проверки; обычным посетителям оно скрыто.

## Скачивание приложения

В блоке «Мобильное приложение» и в подвале есть кнопка «Скачать APK» (`downloads/Noctis-<версия>.apk`; версия берётся из `app/pubspec.yaml`).
Сам файл в репозиторий не входит: после сборки приложения (`app/tools/build_android.ps1`) скопируйте `Noctis-<версия>.apk` в `site/downloads/`.
Размер подставляется из файла при `python build.py`. Для пользователей вне вашей сети соберите приложение с публичным адресом сервера.
На iPhone приложения пока нет, об этом сказано на сайте.

## Устройство

| Файл | Назначение |
|---|---|
| `build.py`, `i18n.py` | сборка страниц из текстов; запускать после правки текстов: `python build.py` |
| `assets/tokens.json` | единые цвета и размеры (светлая и тёмная тема) для сайта и приложения; из него собирается `tokens.css` |
| `assets/site.css`, `site.js` | оформление, переключатель темы и языка |
| `assets/dashboard.js`, `admin.js` | кабинет и страница администратора |
| `assets/i18n.<язык>.js` | строки кабинета (создаются сборкой) |
| `assets/config.js` | настройки сайта (адрес сервера по умолчанию); сборка его не перезаписывает |
| `tests/test_site.py` | проверки: тексты на пяти языках, ссылки, нет внешних адресов и встроенных скриптов, контраст цветов |

Контактный адрес задаёт `CONTACT_EMAIL` в `build.py` — замените на свой.

Сайт работает под строгой политикой безопасности (`script-src 'self'`): встроенных скриптов и внешних ресурсов в нём нет, и добавлять их не нужно.

## Тема и хранение входа

Светлая или тёмная тема выбирается кнопкой в шапке и запоминается в браузере; пока выбора нет — тёмная. Все цвета — переменные из `tokens.css`; приложение берёт те же значения из `tokens.json`.

Токены доступа лежат в `sessionStorage` (до закрытия вкладки) или, если отмечено «Запомнить меня», в `localStorage`. Для статического сайта без серверной части это стандартный компромисс.
