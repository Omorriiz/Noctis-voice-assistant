# Noctis — голосовой ассистент (умная колонка)

Noctis — платформа умной колонки, которая работает у вас дома и не зависит от облачных сервисов. Колонка слушает слово пробуждения
**«Нильс» (Nils)** или «Alexa», понимает речь, отвечает женским русским голосом и умеет:

- говорить время, ставить таймеры и будильники («разбуди меня в 7:30 по будням»);
- сообщать погоду на сегодня в любом городе («какая погода в Казани») — данные Open-Meteo, ключ не нужен;
- играть музыку: из вашей библиотеки, из каталога Jamendo и интернет-радио (других источников нет);
- вести разговор и отвечать на вопросы с помощью локальной языковой модели (Vikhr-Nemo-12B через Ollama);
- работать на пяти языках: русский, английский, испанский, немецкий, французский.

Распознавание речи (faster-whisper), языковая модель и синтез голоса (Silero, голос Xenia) работают на вашем компьютере.
Всё запускается на Windows, WSL не нужен.

## Из чего состоит

| Папка | Что это |
|---|---|
| [`server/`](server/README.md) | Сервер на FastAPI: REST API, WebSocket для колонки, распознавание → ответ → озвучивание, учётные записи, таймеры, музыка, погода, база SQLite |
| [`firmware/`](firmware/README.md) | Прошивка колонки на ESP32-S3: микрофон INMP441, усилитель MAX98357A, экран SSD1306, сопряжение по Bluetooth, обновление по воздуху |
| [`app/`](app/README.md) | Мобильное приложение на Flutter (Android; для iPhone нужен Mac с Xcode): добавление колонки, настройки, таймеры, музыка, история |
| [`site/`](site/README.md) | Сайт и веб-кабинет на пяти языках, страница администратора; сайт раздаёт сам сервер |
| [`wakeword/`](wakeword/README.md) | Инструменты обучения слова пробуждения и готовая модель «Нильс» |
| [`docs/`](docs/) | Подробные описания частей проекта, руководство по проверке на плате |

## Как это работает

```
 колонка (ESP32-S3)                       компьютер с сервером Noctis                  телефон / браузер
 микрофон → слово «Нильс» ─ WebSocket ─►  речь → текст → ответ модели → голос ─►       приложение и сайт
 динамик  ◄── голос и музыка ───────────  таймеры, будильники, музыка, погода          управляют колонкой
                                          база данных SQLite              ◄─ REST API ─┘
```

Слово пробуждения распознаётся прямо на колонке: пока его не произнесли, на сервер ничего не отправляется.

## Быстрый старт

Нужны Windows 10/11, Python 3.12. Для голосовой части — видеокарта NVIDIA (для RTX 50xx — сборка PyTorch с CUDA 12.8 и новее) и [Ollama](https://ollama.com).

**1. Сервер**

```powershell
cd server
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt            # API, база данных, тесты
copy .env.example .env                     # при желании отредактируйте
pip install -r requirements-ai.txt         # голосовая часть (PyTorch ставьте под свою CUDA)
ollama pull OxW/Vikhr-Nemo-12B-Instruct-R-21-09-24:q4_K_M
python -m noctis_server                    # миграции применяются сами, сервер слушает порт 8000
```

Сайт открывается по адресу `http://<адрес компьютера>:8000/`, документация API — `/docs`. Создайте администратора:
`python tools\create_admin.py --email you@example.com` (подробнее — в `server/README.md`).

**2. Прошивка** (плата ESP32-S3 N16R8)

```powershell
pip install platformio
cd firmware
pio run -t upload
```

**3. Приложение** (Android)

```powershell
cd app
flutter pub get
flutter build apk --release --dart-define=NOCTIS_SERVER=http://<адрес компьютера>:8000
```

Затем в приложении создайте учётную запись, нажмите «Добавить колонку» и введите код с экрана колонки — Wi‑Fi и адрес сервера передаются по Bluetooth.

## Проверка

```powershell
server\.venv\Scripts\python.exe -m pytest server\tests site\tests        # сервер и сайт
cd app; flutter test                                                      # приложение
python firmware\tests\run_host_tests.py                                   # логика прошивки на компьютере (нужен gcc/clang или ziglang)
```

Тесты не требуют видеокарты и платы.

## Безопасность и приватность

- Ключ подписи токенов создаётся при первом запуске и хранится в `server/data/secret.key` — сохраните копию.
- Устройства без токена отключены; пароли проверяются по политике (слабые отклоняются), хранятся только хэши.
- Страницы сайта отдаются со строгой политикой безопасности; ключи и пароли скрываются в журналах.
- В кабинете и приложении можно выгрузить свои данные, очистить историю диалогов или удалить учётную запись — только по вашему нажатию.
- Сервер работает по обычному HTTP в локальной сети. Для доступа из интернета поставьте перед ним HTTPS-прокси.

Проверить репозиторий и архивы на случайно попавшие секреты: `python server\tools\scan_secrets.py`.

## Что в репозиторий не входит

Секреты и данные (`.env`, `server/data/`), модели распознавания речи (`server/models/`), собранные приложения (`*.apk`, `*.aab`), ключ подписи Android,
виртуальные окружения и результаты сборки. Список — в `.gitignore`. Файл `firmware/include/config.h` создайте из `config.h.sample`.
